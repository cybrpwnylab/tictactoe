# Tic-Tac-Toe

A two-player, drag-and-drop tic-tac-toe game that runs in the browser. No computer opponent: two humans take turns.

## How to play

1. Open `index.html` in any modern browser (double-click it).
2. X goes first. Drag an X from the pile on the left onto an empty square.
3. Then O drags an O from the pile on the right. Only the current player's pile is active.
4. Get three in a row to win. "New game" resets the board.

## Notes

- Single file, no dependencies or build step.
- Uses pointer events, so it works with mouse and touch.
